# 🛢️ PyMudCement-Optima

## Intelligent Mud & Cement Design Suite

---

## 📖 What is This Software?

**PyMudCement-Optima** is a drilling engineering software that helps engineers design drilling mud and cement for oil wells.

### Why Was It Built?
- Engineers used to do calculations by hand
- This took a long time and had errors
- This software does it automatically and accurately

---

## ✨ Features

### 1. Dashboard
- See the status of all modules at once
- Know what data has been entered
- Get guidance on what to do next

### 2. Drilling Fluids
- Enter mud weight, viscosity, and temperature
- Save data for use in other modules

### 3. Mud Formulation
- Select rock type (Sandstone, Shale, Carbonate, etc.)
- Get recommended mud systems
- Generate complete mud recipe

### 4. Rheology Analysis
- Calculate how mud flows using the Bingham-Plastic model
- View results in a table and graph

### 5. Cementing Design
- Calculate annular volume
- Calculate how much cement is needed
- Design lead and tail slurries
- Calculate spacer and wash volumes

### 6. Plug & Abandonment
- Design cement plugs for well abandonment
- Design plugs for sidetracking
- Design plugs for well suspension

### 7. Pressure Profile
- Visualize mud pressure vs pore and fracture pressure
- Check if you're in the safe drilling window
